## 考察メモ（レポート用）
- 大きいモデルは「範囲外・曖昧」の扱い（安全側に倒す）で 3b より明確に強い。3b は「前に歩いて」を nod に誤変換するなど、危険側の誤りがある。
- 32b と 14b の精度は同じで、14b は 2.3 倍速い。実時間の対話では 14b が最もバランスが良い。
- 32b、14b が間違えたケースは「保守的すぎる clarify」で、危険側の誤りではない。
- 手元の RTX 4060 (8GB) では 14b/32b は載らない（VRAM 不足）。そのため「エッジでは 3b、クラウド GPU では 14b」という使い分けの根拠になる。
